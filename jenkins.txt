Jenkins with Nexus,Sonarqube and Tomcat:::


Create 4 EC2 instances namely jenkins,nexus,sonarqube,tomcat with c7i-flex.large and 20 GB for each.
Connect to all instances and change the hostname to avoid confusion.[hostnamectl set-hostname name].

Jenkins Setup:
Take a instance and install jenkins and also GIT.
Jenkins commands
        yum install java-21-amazon-corretto -y
        sudo wget -O /etc/yum.repos.d/jenkins.repo     https://pkg.jenkins.io/rpm-stable/jenkins.repo
        yum install jenkins -y
        systemctl start jenkins
        systemctl status jenkins
        systemctl enable jenkins 
Access the jenkins dashboard with instance public ip address and port 8080
Manage jenkins ->Tools-> maven installations->Add maven -> mymaven ->save

Plugins to install::
Deploy to container
Nexus artifact uploader
sonarqube scanner
pipeline stage view
pipeline utility steps

Access sonarqube dashboard with public ip and 9000 port.
Manage jenkins-> system-> sonarqube servers->mysonar->URL->credentials[Add ->global->secret text->ID(sonar)
To get the secret ---> sonarqube dashboard->create project-> MyProject->MyToken->Generate
Create a pipeline job in jenkins and configure the job-->pipeline syntax->with sonarqube env->select credentials->generate
In sonarqube dashboard--> after generating token -->click continue->maven -->copy commands and use it in job config.
Also add a stage QualityGate -->pipeline syntax->wait for quality gate->generate and add in job
In SQ dashboard, project->project settings->webhooks->give any name-> URL[jenkins url/sonarqube-webhook/]

This is a Complete CI/CD pipeline with integrating nexus,sonarqube and tomcat.


Pipeline::

pipeline {
    agent {
        node{
            label "dev"
        }
    }
    tools{
        maven "mymaven"
    }
    stages {
        stage('code') {
            steps {
                git "https://github.com/jiyaz48/one.git"
            }
        }
        stage("build"){
            steps{
                sh "mvn clean install"
            }
        }
        stage("CQA"){
            steps{
                withSonarQubeEnv('mysonar') {
                sh '''
                    mvn clean verify \
                    org.sonarsource.scanner.maven:sonar-maven-plugin:sonar \
                    -Dsonar.projectKey=myproject \
                    -Dsonar.host.url=http://18.207.168.93:9000 \
                    -Dsonar.login=a2152d68d340afbc8d89d0b7e543a5c520f276d6
                '''
                }
            }
        }
        stage("QualityGate"){
            steps{
                waitForQualityGate abortPipeline: true, credentialsId: 'sonar'
            }
        }
        stage("Artifact"){
            steps{
                script {
                    def pom = readMavenPom file: 'pom.xml'
                    nexusArtifactUploader(artifacts: [[artifactId: pom.artifactId, classifier: '', file: "target/myweb.war", type: 'war']], credentialsId: 'nexus', groupId: pom.groupId, nexusUrl: '54.224.109.188:8081', nexusVersion: 'nexus3', protocol: 'http', repository: 'myrepo', version: pom.version)
                }
            }
        }
        stage("Deploy"){
            steps{
                deploy adapters: [tomcat9(alternativeDeploymentContext: '', credentialsId: 'cred', path: '', url: 'http://54.205.16.148:8080/')], contextPath: 'myapp', war: 'target/*.war'
            }
        }
    }
    post {
        always{
            mail to: 'jismloves@gmail.com',
            subject: "Build Status: ${currentBuild.fullDisplayName}",
            body: "The build ${env.BUILD_NUMBER} finished with status: ${currentBuild.currentResult}. View logs at: ${env.BUILD_URL}"
           }
      }
}
